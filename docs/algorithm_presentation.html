SafeRide Core Algorithms

Sensor Detection, Trust Weighting, and Data Fusion

1. Sensor-Based Detection Model Objective Data

Collects raw telemetry and dynamically adapts to contextual conditions to detect unsafe events while filtering noise.

Raw Data
Accel, Gyro, GPS
Collected continuously via sliding window processing.
→
Adaptive Thresholds θ(t)
Contextual Tuning
Adjusts base thresholds based on Vehicle Type, Road Condition (α), Traffic (β), and Noise (γ).
→
Event Detection
Speeding, Braking, Turning, Potholes
Detects discrete unsafe events when adaptive thresholds are exceeded within a time window.
Context Adjustment A(t)
1 + α(1-R_c) + β(T_d) + γ(E_n)
Dynamic Threshold θ(t)
θ_base × Mult × A(t)
Risk Scoring weights
Speed (w1), Brake (w2), Turn (w3), Pothole (w4), Slope (w5)
R_sens(t) = [ (w1·C_v + w2·C_b + w3·C_g + w4·P(t) + w5·|S(t)|) / W_total ] × A(t)

2. Trust-Weighted Crowdsourcing Model Subjective Data

Evaluates passenger credibility to prioritize reliable reports and penalize inconsistent ones.

Passenger Report
Manual Hazard Rating
User submits a safety rating (1-5 scale) mapped to a 0-1 risk value.
→
Trust Weight T_i(t)
Credibility Scoring
Evaluated using Consistency Score, Anomaly Score, and Sensor Alignment Score.
→
Weighted Aggregation
Normalized Report Risk
Combines all active reports in the current context, weighted by their respective trust scores.
Consistency Score
Historical reliability
Sensor Alignment
Conformity with sensor ops
Anomaly Penalty
Deviation from norm
R_rep(t) = Σ [ T_i(t) × r_i(t) ] / Σ T_i(t)

3. Non-linear Data Fusion Model Composite Algorithm

Seamlessly merges objective sensor risk and subjective passenger reports into a standardized 0-100 score.

R_sens(t)
Sensor Risk
R_rep(t)
Report Risk
↘ ↙
Data Fusion Engine
Adaptive Weighting λ(t)
Dynamically balances reliance on sensors vs. reports based on data volume. Applies disagreement penalty (φ).
→
Safety Score
0 - 100 Scale
R_trip(t) = λ(t)·R_sens(t) + (1-λ(t))·R_rep(t) + φ·|R_sens(t) - R_rep(t)|
S_trip(t) = 100 × (1 - R_trip(t))
